Affichage du cadre

Mode nuit et luminosité

Sans capteur physique ni entité illuminance, le mode nuit ne s'active que si le mode horaire de secours est coché. Le cadre est masqué en noir et atténué, pas éteint matériellement.

Personnaliser avec du CSS

Le cadre utilise Android Canvas : ce CSS est interprété nativement (couleurs, typographie, arrondis). Ce n'est pas un moteur CSS complet.

Sélecteurs : body, .header, .clock, .date, .metric, .metric-1 à .metric-12, .control, .control-1 à .control-12, .control.on, .control.pressed , .card, .page-tab, .page-tab.active et éléments de texte.

Propriétés prises en charge : color, background-color, font-size, font-weight, border-radius. Couleurs : #RGB, #RRGGBB ou var(--nom). Guide CSS.

Le CSS sera vérifié avant l'enregistrement.
