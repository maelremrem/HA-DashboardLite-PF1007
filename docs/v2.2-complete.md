# HA Frame Studio 2.2.0 — consolidated release candidate

This release targets **Home Assistant integration 2.2.0** and **Android APK 2.2.0** on the PF1007 (Android 6.0.1, API 23). Both parts must be updated together. The changes are not marked production-stable until checked on a physical PF1007.

## New in 2.2.0

- Calendar tiles show up to five upcoming events from the authenticated Home Assistant calendar API
- To-do tiles show up to five pending item names from `todo.get_items`, not only the count
- Bambu tiles can combine separate printer-state, progress-percent and remaining-time entities
- State/threshold/time rules can change the tile's MDI icon, optional color or visibility
- Photos crossfade (0–2500 ms) with configurable quiet hours and a clock overlay
- Upload one or multiple photos from the Studio browser to the selected frame; Studio resizes and compresses locally
- Browse Home Assistant's configured `media_dirs` and sync an album to one frame, with SHA-256 deduplication, on-device downsampling and 100-photo limit
- Home Assistant `ha_frame.sync_media_album` service allows scheduled, per-frame media-folder sync; administrator-only when manually invoked by a user
- Home Assistant `ha_frame.show_alert` supports priorities 0–3, expiration and preemption of urgent messages
- Studio can stage a signed higher-version APK to the chosen frame; the frame verifies SHA-256 and the installed signing certificate, then **requires local confirmation** to install it
- Settings saves the existing installed APK as `backup-original.apk` before opening Android's installer

## Important safeguards

All device operations require the existing LAN API bearer token and the Studio WebSocket commands require a Home Assistant administrator. Frame credentials are not included in exported profiles or layouts.

Photo albums can only read paths inside Home Assistant's configured `media_dirs`. Uploaded images are decoded and reduced on Android; raw files are limited to 6 MB, final images to 96 KB, and the library to 100 photos. Repeated synchronizations skip images already present and do not delete manually uploaded photos. Images are not downloaded from arbitrary external URLs.

APK transfers are limited to 48 MB and use a 30-minute session with ordered chunks. The device checks the complete file hash, package name, version progression and signing certificate. The transfer **never launches the installer**; approving an installation requires the physical frame. Automatic downgrade and unattended root installation are intentionally not implemented.

## Quick start and final test

1. Update the Home Assistant integration through HACS to version 2.2.0 and restart HA.
2. On Fedora, from the updated `main` branch and with the PF1007 connected using ADB, run:

```bash
bash scripts/final-check-fedora.sh
```

This builds the APK, installs it **in place**, starts it and collects crash and memory logs in `build/final-check/`. Do not uninstall the old APK if the debug signing keys do not match.

3. Open **HA Frame Studio**. Configure a Bambu tile with separate state/progress/time sensors, add a calendar and a to-do list, then create a conditional MDI icon.
4. Open Photos, select an album from Home Assistant Media, synchronize it to the frame, and check quiet hours and transitions.
5. In Maintenance, request a screenshot and confirm log/diagnostic visibility. For an APK test, stage a properly signed newer APK from Studio, then go to Android Settings on the frame to approve it.

You only need to perform this one final acceptance round after installing both components.

### Useful Home Assistant actions

```yaml
action: ha_frame.show_alert
data:
  device_id: "YOUR_FRAME_DEVICE_UUID"
  title: "Porte ouverte"
  message: "Vérifier la porte du garage"
  duration: 20
  priority: 3
```

```yaml
action: ha_frame.sync_media_album
data:
  device_id: "YOUR_FRAME_DEVICE_UUID"
  source: local
  folder: Famille
```

The `source` field is the name configured in Home Assistant `media_dirs`; it is not a filesystem path or a URL. To schedule album synchronization, use a normal Home Assistant automation with the second action.

## Limitations and recovery

- Up to five calendar events and five to-do items are displayed at once. More remain accessible in Home Assistant.
- Albums synchronize **additively**. Remove images separately in Studio if you need to reclaim space.
- Home Assistant Media integration sources backed by remote providers are not imported automatically; album sync is limited to directories configured under `media_dirs`.
- Remote APK transfer only prepares an installation. A signed APK cannot be silently installed, downgraded or rolled back without Android's permissions and local confirmation.
- Recovery copy location: `Android/data/dev.maelab.haframe/files/updates/backup-original.apk`. Keep an independent backup of the previous APK and frame settings before your first upgrade.
- The local photo cache, camera stream, priority queue and album transfer require physical testing for 24-hour stability and memory consumption on this Android 6 device.

If Android crashes, provide `build/final-check/<date>/android-crashes.log` and `memory.txt`. Never clear app data as the first troubleshooting step.
